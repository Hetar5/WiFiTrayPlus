# WiFiTrayPlus

A lightweight Windows application that displays Wi-Fi signal strength in the system tray.

## Features

- Displays Wi-Fi signal strength using a custom colored tray icon.
- Five signal levels, from no signal to excellent signal.
- Left-click opens the Windows list of available Wi-Fi networks.
- Right-click provides access to Wi-Fi information and application controls.
- Displays the currently connected Wi-Fi network name.
- Shows Wi-Fi connection information and link speed.
- Starts automatically with Windows.
- Designed to run quietly in the system tray.

## Version

**WiFiTrayPlus 1.0.5**

## Requirements

- Windows 10 or later
- Wi-Fi adapter

## Installation

Download the latest installer from the **Releases** section and run it.

## Known limitation

When switching between Wi-Fi networks, the displayed network name may take up to approximately 30 seconds to update.
