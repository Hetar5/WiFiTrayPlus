
# WiFiTrayPlus

WiFiTrayPlus is a lightweight Windows utility that displays the current Wi-Fi signal strength directly in the system tray.

Instead of the standard Windows Wi-Fi indicator, WiFiTrayPlus uses clear, color-coded icons representing five signal levels, making the current signal strength easy to recognize at a glance.
![WiFiTrayPlus icon](Screenshots/WiFiTrayPlus-icon.png)
## Features

- Five Wi-Fi signal strength levels.
- Automatic update of the tray icon according to the current signal strength.
- Clear, color-coded Wi-Fi icons.
- Wi-Fi connection information available from the tray menu.
- Quick access to Windows network settings.
- Direct access to Windows network troubleshooting.
- Runs quietly in the system tray.
- Starts automatically with Windows.

## Wi-Fi information

The **Informacje o WiFi** option provides detailed information about the current Wi-Fi connection.

## Tray menu
![WiFiTrayPlus menu](Screenshots/WiFiTrayPlus-menu.png)
Right-click the WiFiTrayPlus icon to access:

- **Informacje o WiFi** — displays information about the current Wi-Fi connection.
- **Otwórz ustawienia sieci** — opens Windows network settings.
- **Rozwiąż problemy** — directly starts Windows network troubleshooting.
- **Zakończ** — closes WiFiTrayPlus.

## Version

**WiFiTrayPlus 1.0.6**

## Requirements

- Windows 10 or later
- Wi-Fi adapter

## Installation

Download the latest `.msi` installer from the **Releases** section and run it.

WiFiTrayPlus runs in the Windows system tray after installation.

## Known limitation

When switching between Wi-Fi networks, the displayed network information may take a short time to update.
